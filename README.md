# 🛡️ NetGuard – Network Monitoring System

## 📌 About the Project

NetGuard is a beginner-level Computer Networks mini project developed using Python and Flask.

It is a simple web application that monitors internet connectivity and displays the local IP address and network connection status.

## ✨ Features

- Check internet connectivity
- Display local IP address
- Show Connected / Disconnected status
- Refresh network information
- Simple and user-friendly dashboard

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Socket Programming

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/NetGuard.git
```

### 2. Open Project Folder

```bash
cd NetGuard
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

```bash
venv\Scripts\activate
```

### 5. Install Flask

```bash
pip install flask
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Browser

```text
http://127.0.0.1:5000
```

## 🖥️ Application Output

The dashboard displays:

- Internet Connection Status

## 🎯 Objective

The main objective of this project is to understand basic computer networking concepts, including IP addressing, network connectivity, ping commands, and client-server architecture.

## 📚 Concepts Used

- IP Addressing
- ICMP and Ping
- Network Connectivity
- Client-Server Architecture
- Socket Programming
